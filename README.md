**VigLens**

VigLens is a sports betting analytics project I built using JavaScript and React to compare sportsbook odds, calculate no-vig probabilities, and identify potential value across different books.

I originally started the project to better understand how sharp books like Pinnacle price markets compared to softer books and DFS platforms like PrizePicks. Instead of relying on public betting trends or social media picks, I wanted to build something that focused more on pricing, implied probability, and line movement.

**Features**

Compare odds across sportsbooks
Calculate implied probability and no-vig odds
Analyze PrizePicks prop lines against sharp books
Track closing line value (CLV)
Convert odds between American, decimal, and implied probability formats
Kelly Criterion calculator for bankroll management
Highlight potential edge opportunities based on sportsbook pricing

**Tech Stack**

JavaScript
React
Probability and odds calculation logic
